How to Use

사용 방법

  1. 발표 주제 입력

    발표의 핵심 주제를 한 문장으로 입력합니다.

  2. 발표 대본 입력

    실제 발표할 내용을 그대로 붙여넣습니다.

  3. AI 분석 실행

    AI가 구조, 점수, 개선점, 예상 질문을 생성합니다.

  4. 결과를 바탕으로 수정

    수정 대본과 체크리스트를 활용해 발표를 다시 연습합니다.

FAQ

자주 묻는 질문

AI 분석 결과는 항상 정확한가요?

AI 분석은 발표 개선을 위한 참고 자료입니다. 최종 발표 내용은 사용자가 직접 판단하고 수정해야 합니다.

API 키는 어디에 저장하나요?

API 키는 코드에 직접 작성하지 않고 Vercel의 Environment Variables에 저장합니다.

응답이 늦으면 어떻게 되나요?

분석 중 안내 메시지가 표시되며, 응답 시간이 너무 길거나 API 오류가 발생하면 사용자에게 오류 메시지를 보여줍니다.
