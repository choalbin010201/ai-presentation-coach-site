# 서비스 기획서 - AI 발표 코치

## 1. 서비스 개요

### 서비스명

AI 발표 코치

### 서비스 목적

발표를 준비하는 사용자가 발표 대본의 구조와 전달력을 스스로 점검하기 어려운 문제를 해결한다.  
사용자는 발표 주제와 대본을 입력하고, AI는 발표 구조 분석, 점수, 개선점, 예상 질문, 수정 대본을 제공한다.

## 2. 타겟 사용자

- 대학 수업 발표를 준비하는 학생
- 팀 프로젝트 발표를 준비하는 학생
- 졸업 프로젝트 또는 공모전 발표를 준비하는 사용자
- 발표 후 예상 질문을 미리 대비하고 싶은 사용자

## 3. 페이지 / 섹션 구성

| 섹션 | 목적 |
|---|---|
| 홈 | 서비스의 핵심 가치와 시작 버튼 제공 |
| 서비스 소개 | 사용 대상과 문제 상황 설명 |
| AI 발표 분석 | 사용자가 발표 주제와 대본을 입력하고 AI 결과를 확인 |
| 사용 방법 | 서비스 이용 순서 안내 |
| FAQ | 결과 신뢰도, API 오류, 보안 안내 |

## 4. 핵심 기능

사용자가 발표 주제와 대본을 입력하면 AI가 다음 항목을 생성한다.

- 예상 발표 시간
- 발표 구조 분석
- 발표 점수
- 장점
- 개선점
- 수정된 발표 대본
- 예상 질문과 답변
- 발표 전 체크리스트
- 핵심 조언

## 5. AI 기능 입력 / 출력 정의

### 입력

```json
{
  "topic": "AI 발표 코치 서비스",
  "presentation_type": "대학 수업 발표",
  "target_time": 5,
  "script": "발표 대본 내용"
}
```

### 출력

```json
{
  "estimated_time_text": "3분 20초",
  "analysis": {
    "structure_analysis": {},
    "score": {},
    "strengths": [],
    "improvements": [],
    "revised_script": "",
    "expected_questions": [],
    "checklist": [],
    "one_sentence_summary": ""
  }
}
```

## 6. 실패 처리 기준

| 실패 상황 | 사용자 안내 |
|---|---|
| 빈 입력 | 발표 주제와 발표 대본을 모두 입력해주세요. |
| 짧은 대본 | 발표 대본은 최소 50자 이상 입력해주세요. |
| API 오류 | AI 분석 중 오류가 발생했습니다. 잠시 후 다시 시도해주세요. |
| API 키 누락 | 배포 환경의 환경 변수 설정을 확인해야 합니다. |
| 응답 지연 | AI 응답이 지연되고 있습니다. 잠시 후 다시 시도해주세요. |

## 7. 테스트 케이스

| 테스트 | 입력 | 예상 결과 |
|---|---|---|
| 정상 입력 | 주제와 300자 이상 대본 | AI 분석 결과 표시 |
| 빈 입력 | 주제 또는 대본 없음 | 필수 입력 안내 메시지 |
| 짧은 입력 | 50자 미만 대본 | 짧은 대본 안내 메시지 |
| API 오류 | 잘못된 API 키 또는 API 장애 | fallback 또는 오류 안내 |
| 모바일 접속 | 390px 화면 | 레이아웃 깨짐 없이 표시 |
